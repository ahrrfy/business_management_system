## ١. تحليل المتطلبات والواقع التشغيلي السابق (Requirements & Context)

### طلب المستخدم الصريح:
1. «اريد تحميل pdf لقسائم الرواتب للموظفين في ملف واحد وتصديرها ايضا اضافة الى القسيمة الخاصة لكل موظف الموجودة في صف الراتب»
2. «يعني ملف pdf واحد يحتوي على القسائم الموظفين كلهم»

### الواقع التشغيلي القائم قبل التعديل:
1. كان النظام يوفر دالة طباعة فردية `printPayslip(d: PayslipData)` تقوم بتغليف قسيمة موظف واحد في مستند A4 أحادي عبر `wrapA4Doc` وتفتح نافذة الطباعة.
2. عند رغبة مسؤول الموارد البشرية أو المحاسب في تصدير قسائم رواتب شهر كامل لجميع الموظفين (مثلاً 20 أو 50 موظفاً) لأرشفتها في ملف PDF واحد أو طباعتها دفعة واحدة لتوقيعها وتوزيعها، كان يضطر لفتح كل قسيمة يدوياً وطباعتها على حدة، مما يهدر الوقت والجهد.
3. لم تكن مكتبة الطباعة الرسمية تحتوي على دالة مخصصة لدمج مستندات A4 متعددة الصفحات مع صون فواصل الصفحات الطباعية الصارمة (`page-break-after: always; break-after: page;`) وأشرطة الأدوات الموحدة.

## ٢. الحلول الهندسية المنفذة

### ١. محرك المستندات متعددة الصفحات A4 (`wrapMultiA4Doc` في `client/src/lib/printing/docHtml.ts`):
- بناء وتصدير دالة عامة `wrapMultiA4Doc(title, pagesContent, options)` تغلف مصفوفة من محتويات الصفحات في هيكل HTML رسمي.
- كل صفحة تأخذ الحاوية القياسية `<div class="page" data-page-index="N">` بقياسات A4 الدقيقة (794px × 1123px).
- ضبط قواعد CSS الطباعية بدقة:
  ```css
  @media print {
    .page {
      margin: 0 !important;
      box-shadow: none !important;
      page-break-after: always !important;
      break-after: page !important;
    }
    .page:last-child {
      page-break-after: auto !important;
      break-after: auto !important;
    }
  }
  ```
  هذا يضمن أن كل قسيمة تقع في صفحتها المستقلة بدقة متناهية دون أي تداخل، ويمنع ظهور صفحة بيضاء فارغة في نهاية المستند.
- تزويد المستند بشريط أدوات موحد (`doc-toolbar`) يحتوي على أزرار «طباعة المستند» و«حفظ كملف PDF» وشارة تعريفية بعدد الصفحات ومسمى المسيّر.

### ٢. محرك تصدير قسائم الرواتب المجمعة (`client/src/lib/printing/printPayslip.ts`):
- فصل وتصدير منطق بناء هيكل القسيمة في دالة مستقلة وقابلة لإعادة الاستخدام:
  `renderPayslipHtml(d: PayslipData): string`
  تحتوي على كافة البيانات القانونية والمالية: ترويسة الشركة، بطاقات الموظف، جدول الاستحقاقات والاستقطاعات، صافي الراتب، التفقيط بالدينار العراقي، التزامات رب العمل (الضمان ومكافأة نهاية الخدمة)، لقطات التجزئة والتشفير التدقيقية (hashes)، ومساحة التواقيع الرسمية الثلاثية.
- الإبقاء على دالة الطباعة الفردية الأصلية `printPayslip(d: PayslipData)` لضمان التوافق التام.
- بناء وتصدير دالة التصدير المجمعة:
  `printBatchPayslips(slips: PayslipData[], meta?: { title?: string; period?: string }): boolean`
  تستقبل مصفوفة قسائم الموظفين وتولد مستند A4 موحد لجميع الموظفين.

### ٣. تطوير واجهة مسيّر الرواتب (`client/src/pages/Payroll.tsx`):
- استخراج دالة مساعدة نقية وموحدة لبناء كائن القسيمة:
  `getPayslipData(item: RunItem): PayslipData | null`
  تضمن استخراج دقيق للفرع، الراتب الأساس، البدلات، الخصومات، والمدفوعات الفعلية.
- إضافة زر **«تصدير قسائم الرواتب (PDF)»** إلى رأس بطاقة بنود المسيّر بجانب زر "تصدير Excel":
  ```tsx
  <Button
    variant="outline"
    size="sm"
    disabled={!visibleItems.length}
    onClick={onExportAllPayslips}
    title="تصدير وتحميل قسائم الرواتب لكافة الموظفين المعروضين في ملف PDF موحد"
  >
    <FileText className="size-4" /> تصدير قسائم الرواتب (PDF)
  </Button>
  ```
- إضافة زر طباعة فوري ومباشر بأيقونة طابعة `<Printer className="size-3.5" />` في صف كل موظف، يتيح طباعة أو حفظ قسيمة الموظف الفردية بصيغة PDF مباشرة بضغطة زر واحدة دون اشتراط فتح نافذة المعاينة مسبقاً، مع الإبقاء على زر «القسيمة» للمعاينة التفصيلية.
