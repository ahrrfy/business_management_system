# معيار البحث والفلاتر في شاشات النظام

هذا المعيار يحوّل البحث والفلاتر من إضافات متفرّقة إلى عقد ثابت لكل شاشة قائمة. لا يعني أن كل
شاشة تحتاج الحقول نفسها؛ المطلوب أن تعكس الفلاتر أسئلة المستخدم الفعلية في تلك الوظيفة.

## العقد الإلزامي

1. البحث والفلاتر الخادمية تعمل على كامل النتائج، لا على الصفحة الحالية فقط.
2. تغيير أي فلتر يعيد الترقيم إلى الصفحة الأولى، والتصدير يستخدم الفلاتر نفسها.
3. كل حقل فلتر يحمل تسمية ظاهرة؛ لا يُعتمد على `placeholder` وحده.
4. يظهر عدد الفلاتر النشطة وزر موحّد لمسح البحث والفلاتر.
5. الفلاتر الكبيرة للكيانات (عميل، مورد، موظف، منتج) تستخدم منتقي بحث، لا `<select>` طويلًا.
6. البحث النصي مؤجّل 200–300ms، واعٍ بالعربية، ويصف للمستخدم الحقول التي يبحث فيها.
7. حالة «لا نتائج» تميّز بين خلو السجل وعدم وجود نتائج مطابقة للفلاتر.
8. حالة الفلاتر المهمة تُحفظ في عنوان الصفحة عندما تكون الشاشة رابطًا تشغيليًا متداولًا.

## القدرات التشغيلية

تُضاف القدرات بحسب وظيفة الشاشة، ولا تُعرض أزرار بلا قيمة تشغيلية:

- **التصدير:** يصدّر جميع الصفوف المطابقة للفلاتر، لا الصفحة الحالية، ويحافظ على الأعمدة الدلالية
  والأرقام بصيغة صالحة للتحليل.
- **الطباعة:** تطبع مستند العمل أو التقرير المرئي بالهوية الرسمية، مع الفترة والفرع والفلاتر النشطة.
- **التحديث:** للشاشات الحية والطوابير، مع حالة تحميل تمنع النقر المتكرر وتوضح آخر تحديث.
- **الترقيم:** إلزامي للقوائم الكبيرة، خادمي عند نمو البيانات، ويعود للصفحة الأولى عند تغيير الفلاتر.
- **الفرز:** للأعمدة التي تجيب عن سؤال تشغيلي؛ ويكون خادميًا في القوائم المصفحة من الخادم.
- **الإجراءات الجماعية:** فقط حين يكون الإجراء آمنًا ومتجانسًا وقابلًا للتراجع أو التأكيد.
- **الاستيراد والإضافة:** يظهران في شاشة البيانات الأساسية أو التشغيلية التي تسمح الصلاحيات بتعديلها.
- **حالة الخطأ والتحديث:** الخطأ لا يُعرض كجدول فارغ؛ يظهر سبب مفهوم وزر إعادة المحاولة.

## الحد الأدنى حسب نوع الشاشة

| نوع الشاشة | البحث والفلاتر المطلوبة |
|---|---|
| البيانات الأساسية | الاسم/الرمز/الهاتف + الحالة + التصنيف/الفرع |
| السجلات المالية | رقم المستند/الطرف/الوصف + النوع + الحالة + الفرع + الفترة + طريقة الدفع |
| المبيعات والمشتريات | رقم الفاتورة/الطرف + الحالة + الفرع + الفترة + الموظف/المندوب |
| المخزون | المنتج/SKU/الباركود + الفرع + الفئة + حالة المخزون |
| الموارد البشرية | الموظف/الرقم + القسم + الفرع + الحالة + الفترة عند وجود حركة |
| الطوابير التشغيلية | الرقم/الطرف + المسؤول + الأولوية + الحالة + تاريخ الاستحقاق |
| التقارير التحليلية | الفترة + الفرع + أبعاد التقرير؛ البحث النصي فقط إن كانت النتائج سجلات قابلة للتعيين |

## القياس

يشغّل الأمر `pnpm audit:filters` جردًا آليًا لشاشات الجداول وإشارات التغطية الحالية. الجرد أداة
توجيه وليس حكمًا وظيفيًا نهائيًا؛ فالتقرير التجميعي قد يحتاج أبعادًا وفترة من دون بحث نصي.
