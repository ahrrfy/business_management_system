# استعادة MySQL وإدارة النسخة والوسائط

هذه أدوات مختبر محلي، وليست مساراً لإعادة تعيين حساب إنتاج أو تشغيل نسخة كتابة منافسة.

## استعادة نسخة جديدة

`node --import tsx scripts/isolated-local-restore.mjs --sql <absolute.sql> --context desktop-linux --evidence <new-private-directory> --secrets-file <local-escrow-file> --prepare-mysql --bootstrap-admin`

- يلزم Docker محلي عبر named pipe أو Unix socket وصورة MySQL المثبتة؛ لا سحب صور. الحاوية جديدة ذات token، شبكة none، بلا منافذ أو bind mounts، والأحداث والتشغيل التلقائي معطلان.
- `--prepare-mysql` يجرد TRIGGER/ROUTINE/VIEW/EVENT. يسمح بإنشاء `erp_app@%` المفقود للمشغلات فقط، بحالة ACCOUNT LOCK وكلمة عشوائية غير منقولة من الإنتاج، وصلاحيات SELECT/INSERT/UPDATE/TRIGGER ضمن erp. أي definer مجهول أو نوع شيفرة غير مراجع يفشل مغلقاً. لا تعديل لحساب MySQL موجود ولا استبدال المشغلات بـroot.
- `--bootstrap-admin` اختياري وصريح، ويحتاج التهيئة. يُنشئ حساب إدارة نسخة منفصلاً عشوائياً، بفرع فعال صريح، وانتهاء وصول بعد24 ساعة. لا يعيد تفعيل مستخدم مستعاد ولا يبدّل اعتماده. لا يستدعي seed. كلمته تحفظ قبل INSERT في `recovery-admin.private.json`؛ تجزئتها عبر hashPassword الأصلي.
- يجب أن يكون مجلد الأدلة خاصاً قبل bootstrap: POSIX بلا صلاحيات group/other؛ Windows يسمح فقط للمستخدم الحالي وSYSTEM وAdministrators. لا يكفي mode0600 على Windows. جهّز أباً جديداً بصلاحيات مقيدة، وتحقق من ACL؛ لا تغيّر صلاحيات مجلد أسرار/بيانات مشترك قائم.
- بصمة كل أعمدة كل المستخدمين المستعادين تُقارن قبل/بعد الإضافة. الحاوية وكلمة مختبرها تبقيان محفوظتين؛ الأداة توقف الحاوية في finally ولا تزيلها.

`DEFINERS_PRESENT` يثبت حضور الهويات، وليس كل الصلاحيات أو نجاح معاملات الأعمال. قبول التعافي يحتاج كتابة حقيقية تستدعي مشغلاً مستعاداً، والتحقق من أثره ثم rollback، واختبار رفض DDL بحساب التطبيق. الحساب الإداري الجديد يحتاج دخولاً فعلياً وتسجيل TOTP جديداً وتأكيده ورفض replay، ثم فحص JWT والجلسة وبوابة الإدارة، مع إعادة بصمة المستخدمين الأصليين. لا تعطل 2FA ولا تنقل TOTP من حساب أصلي. حساب النسخة بديل لإدارة التعافي؛ لا يثبت استعادة دخول الحساب الأصلي.

## استعادة الوسائط المرجعية

`node scripts/recovery-media.mjs --mode inventory --references <reference-manifest.json> --destination <private-absolute-mirror> --secrets-file <local-read-credentials> --max-bytes 1073741824`

بعد مراجعة تقرير الحجم والتوافر، شغّل الأمر نفسه بـ`--mode copy`. لا تعدّ inventory نسخة وسائط.

- يقرأ فقط نطاقَي single/studio وsingle/storefront-customizer المطلوبين، وينزل مفاتيح manifest الصريحة. لا PUT/DELETE أو sync، ولا تعديل لصلاحيات التخزين أو حساب الإنتاج.
- حد الجرد12 طلب List وحد التنزيل6000 طلب Get، بلا retries تلقائية، وأربع قراءات متزامنة، ومدة أقصاها15 دقيقة للشبكة. يُرفض مجموع فوق السقف قبل GET؛ السقف الأعلى1GiB، والكائن25MiB. يقبل Standard فقط لتجنب رسوم استرجاع الفئة الباردة؛ لا يضمن مجانية الحساب أو بقاء حصته الشهرية.
- يتحقق من الحجم وETag ثم SHA256 المتوقع لكل كائن، وينشر محلياً حصرياً بلا overwrite، ويعيد استعمال الملفات الصحيحة دون تنزيل. يحفظ الأجزاء المؤقتة والملفات القديمة، حتى عند الفشل.
- تقرير REFERENCE_BYTES_VERIFIED يتطلب كل المفاتيح بلا نقص أو خطأ. يربط التقرير ببصمة manifest ومصدر التخزين؛ احتفظ به مع SQL/إصدار التطبيق والمفاتيح الخاصة خارج Git. لا تعمم تغطية manifest على مراجع JSON أو روابط خارجية لم تُجرَد.
- عند403: توقف ووفّر مرآة محلية أو اعتماداً صالحاً للقراءة فقط؛ لا تحاول تغيير حساب أو سياسة R2. الأداة تطلب List/Get فقط، لكنها لا تثبت أن الاعتماد نفسه يفتقد صلاحيات الكتابة.
- قبول التشغيل المحلي اللاحق: إعادة مطابقة الملفات كلها دون شبكة، ثم قراءة عينة متنوعة بسائق FsImageStore من جذر objects في test/development داخل مختبر معزول. حظر fs في الإنتاج يبقى قائماً.

مرجع حدود الكلفة: [تسعير R2 الرسمي](https://developers.cloudflare.com/r2/pricing/)؛ الكلفة الفعلية والحصة المتبقية تعتمدان على الحساب، ولا تثبتهما إعدادات المشروع.

## التراجع والتحقق

التراجع هو إيقاف المختبر، مع إبقاء قاعدة المصدر والوسائط وملفات الأدلة. ابدأ نسخة جديدة عند الحاجة؛ لا تستعد قاعدة قديمة فوق معاملات جديدة. حساب النسخة المؤقت ينتهي تلقائياً ولا يُحذف، ولا يُنقل للإنتاج. فشل وسائط أو اعتماد لا يبرر تعديل المستخدم الأصلي أو وصف التعافي بأنه مكتمل.

الفحوص المركزة: `node --test scripts/backup-recovery-safety.test.mjs scripts/isolated-local-restore.test.mjs scripts/recovery-closure.test.mjs`، مع BACKUP_TEST_GPG وBACKUP_TEST_GPG_MSYS في Windows لتجربة تشفير اصطناعية فعلية. CI يربطها بوظيفة backup-safety المطلوبة؛ لا مفاتيح إنتاج أو قاعدة حقيقية مطلوبة لتلك الوظيفة.
