# إصلاح تكامل المتجر والتوصيل — 2026-10-28

العقد المالي: بضاعة 40,000 + أجرة عميل 5,000 = تحصيل عند الباب 45,000 مرة واحدة. فاتورة البضاعة وCOD يبقيان 40,000، وتبقى أجرة المندوب منفصلة. إذا دُفعت البضاعة قبل إعادة الإسناد فالمتبقي عند الباب 5,000 فقط؛ ومع التوصيل المجاني المدفوع مسبقاً يصبح صفراً. لا تغيير لقيمة الطلب التاريخية.

## المعالجة

- مصدر الجاهز يفصل أجرة المتجر عن البضاعة ويشتق المتبقي من الفاتورة الحالية ومدفوعاتها ومرتجعاتها. يستبعد المستندات الميتة، ويحفظ هوية الفاتورة عند إعادة الإسناد.
- القائمة والتفاصيل تضيفان `amountDueAtDoor` دون تغيير `total`. حوار المتجر وحوار التوصيل والملصق والبوليصة والمغادرة تستعمل مبالغها الصحيحة، وتثبت أجرة المتجر عند اختيار الجهة.
- جسر الباركود يحفظ السائق والمستلم والعنوان والملاحظات، ويرفض أجرة تخالف الطلب. العرض والمستندات بعد الالتزام تستعمل بيانات الإرسالية المثبتة؛ لا تعديل لهوية CRM المشتركة.
- الإسناد التلقائي يفرض فرع الفاعل في الراوتر والخدمة؛ يبقى العبور المشروع للمالك/الأدمن متاحاً.
- لا يُختم طلب مرتبط بتوصيل كمُسلّم اعتماداً على سداد الفاتورة وحده. يلزم دليل تسليم حقيقي، وتفشل العملية دون أثر في الحالة أو الولاء أو الإشعارات عند غياب الدليل أو انشغاله.
- إعادة إسناد إرسالية متجر ملغاة تحافظ على الفاتورة والإرسالية وأثر المخزون الأصلي وتحدّث جهة الطلب وحالته. حارس منع العهدة المزدوجة لفواتير ONLINE باقٍ.
- بصمة المعاينة تشمل البنود المرتبة والعنوان والإحداثيات والعميل والمبالغ والأجرة، وتُطابق داخل معاملة إصدار الفاتورة والإرسالية. تُحفظ هوية إعادة المحاولة في المعاملة نفسها؛ الاستعادة التاريخية تعمل بعد الشحن وبعد التسليم الحقيقي دون تكرار مالي.
- الأقفال الجديدة التي قد تعكس ترتيب مسار قائم لا تنتظر. تعاد قراءة الهوية/الدليل الحالي بقفل `NOWAIT`؛ التعارض يرجع المعاملة كاملة برسالة عربية قابلة للتصرف، مع بقاء ترتيب أقفال البيع الأصلي.
- جرد الصلاحيات المولّد تحدّث في 57 موضع مصدر فقط؛ تحقق مستقل أثبت عدم تغير أي صلاحية أو منحة.

## بروتوكول الفريق

ثلاث شرائح تنفيذ في أشجار معزولة بملكية ملفات مسجلة، ثم دمج لدى قائد واحد ومراجعتان مستقلتان. أغلقت ملاحظات التنافس والاستعادة قبل تجميد المصدر. اختبارات الحساسية أثبتت أن تعطيل NOWAIT يعيد فشل اختبار المورد المشغول. لا خطافات اختبار داخل كود الإنتاج.
