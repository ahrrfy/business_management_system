لغة القالب

أنواع الحقول المدعومة

كل حقل يحدد شكل الإدخال والتحقق والتبعية، من دون بناء نموذج جديد لكل منتج.

TEXT

نص قصير

اسم المستلم، عبارة الطباعة، أو رقم مرجعي.

TEXTAREA

نص طويل

رسالة إهداء أو تعليمات تنفيذ مفصلة.

SELECT

قائمة اختيار

نوع الورق، الخدمة، أو خيار التغليف.

SWATCH

اختيارات مرئية

لون، خامة، أو تشطيب يسهل مقارنته بصرياً.

FILE

مرجع ملف

اسم أو مرجع تصميم العميل قبل تسليم الملف الفعلي.

NUMBER

قيمة رقمية

قياس، عدد نسخ، أو كمية إضافية قابلة للتحقق.

التبعيات تعمل فوق هذه الأنواع: إظهار ملف التصميم فقط عند اختيار نوع التنفيذ الذي يحتاجه.
