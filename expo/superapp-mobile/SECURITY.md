# حدود أمان تطبيق Expo

## حدود إصدار المتجر

المتصفح وExpo Go يعرضان المعاينة فقط. يملك البناء الأصلي مسارات مثبتة بالجهاز: دخول و2FA، مركز المالك حسب الدور، «يومي»، سجل الحضور الشخصي، قسيمة الراتب بعد 2FA جديد، طلب/سحب الإجازة، ومهمة اليوم. لا توجد موافقات مالية أو اختيار موظف/فرع أو مسار URL حر، ولا تحتوي الحزمة أسراراً أو مفاتيح توقيع. يسمح مسار الإصدار الحالي بأثر Android للاختبار الداخلي فقط؛ إرسال Production وApp Store قراران منفصلان.

## عقد التكافؤ قبل ربط بيانات حقيقية

1. **إثبات الجهاز:** مفتاح P-256 غير قابل للتصدير في Android Keystore وiOS Keychain/Secure Enclave. يوقع النقل الأصلي الطلبات بcanonical bytes المطابقة للخادم.
2. **الجلسة والقفل:** session cookie لا يمر إلى AsyncStorage أو TypeScript. Android يشفره بمفتاح Keystore يتطلب نافذة مصادقة نظامية قصيرة؛ iOS يخزنه في Keychain بـ`biometryCurrentSet`. الانتقال إلى الخلفية يفصل شجرة الشاشات ويمسح حمولة مساحة العمل من ذاكرة React، والعودة تتطلب فتحاً محلياً جديداً. Android يمنع الالتقاط، وiOS يحمي لقطة مبدل التطبيقات دون ادعاء منع لقطة الشاشة مطلقاً.
3. **الأفعال الحساسة:** الاعتماد، تنزيل/تصدير المستندات، وتغيير بيانات الدفع تتطلب تذكرة step-up مستقلة قصيرة العمر؛ لا يعاد استعمال تحقق الدخول.
4. **النقل:** HTTPS فقط. تثبيت الشهادة لا ينفذ في JavaScript؛ يجب أن يكون في طبقة أصلية مراجعَة قبل الإنتاج.
5. **الإشعارات والروابط:** لكل Super Arabia جدول أجهزة وoutbox مستقلان، مختلفان عن FCM القديم وتطبيق العميل. رمز Expo مشفر في الخادم ومفهرس ببصمته فقط؛ لا مبالغ أو رواتب أو بيانات شخصية في إشعار مقفل، ولا روابط عميقة حرة. الوجهات قاموس مغلق (`center` و`my-day` و`account`) بلا IDs أو query parameters.
6. **إبطال الحساب:** logout، إلغاء الجلسات، تغيير/إعادة تعيين كلمة المرور، تعطيل الحساب، وإنهاء الموظف تلغي ربط الإشعار للأجهزة المعنية بعد نجاح المعاملة. تعطل قناة التسليم لا تعكس تغيير الحساب.
7. **البيانات:** يفرض الخادم الشركة والفرع والدور من الجلسة، ولا يقبل `employeeId` أو `branchId` من تجربة الموظف الشخصية.

أي بناء متجر أو TestFlight يتوقف عند غياب أحد هذه البنود.

## حالة الإثبات الحالية

- اختبارات Kotlin للوحدة تغطي canonical request ورفض endpoint/pin غير الآمن؛ لا تثبت BiometricPrompt أو pin mismatch على جهاز فعلي.
- كود iOS موجود للمسار نفسه، لكن Windows لا يستطيع بناء أو اختبار Swift/Keychain/ATS. لا TestFlight ولا إنتاج قبل تمرير هذا المسار على iPhone فعلي.
- لا توجد بيانات موظفين أو قوائم مخزون أو قسائم أو مبالغ في cache محلي. PDF الشخصي ملف cache قصير العمر يُحذف بعد إغلاق ورقة المشاركة، ويستلزم فتح حماية الجهاز قبل التصدير.
- تبقى الإشعارات غير فعّالة في المعاينة ما لم يمرر البناء `EXPO_EAS_PROJECT_ID` المراجع، وتبقى الإرساليات متوقفة خادمياً ما لم يعيّن المشغل `SUPERAPP_EXPO_PUSH_ENABLED=true` في البيئة الصحيحة.
