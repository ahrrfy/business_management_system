# ملاحظات أمن التبعيات — customer-store-mobile

> سجلٌّ للثغرات المعروفة والمقبولة قصداً في تبعيّات هذا التطبيق (Expo / React Native)،
> مع مبرّرها وشرطِ إغلاقها. الغاية: ألّا يُعاد تدقيقُ ثغرةٍ عولجت قرارُها، وأن تُغلَق فورَ توفّر إصلاحٍ من المنبع.

## `image-size` — ثغرتا حجب خدمة (DoS) — **مقبولةٌ مؤقّتاً، بانتظار المنبع**

| البند | القيمة |
|---|---|
| الحزمة | `image-size` (الإصدار المثبَّت `1.2.1`) |
| النوع | **تبعيّة متعدّية (transitive)** عبر **Metro** (حزمة بناء React Native) — ليست تبعيّة مباشرة |
| التنبيهات | `CVE-2025-71330` / `GHSA-w3rx-r6r6-pgpr` (محلّل ICNS) · `CVE-2025-71329` / `GHSA-5p2g-fcmc-qvqq` (محلّلا JXL/HEIF) |
| الأثر | حجب خدمة بحلقةٍ لا نهائية عند تحليل صورةٍ مشوَّهة — **لا تنفيذ كود ولا تسريب بيانات** |
| النطاق المصاب | `<= 2.0.2` |
| إصدار مُصحَّح | **لا يوجد** حتى تاريخه — آخر إصدارٍ منشور `2.0.2` نفسه داخل النطاق المصاب |

### لماذا الخطر الواقعيّ ≈ صفر هنا
- `image-size` يعمل **وقت البناء فقط** (Metro يقيس أبعاد الأصول أثناء التحزيم) — **لا يعمل على أجهزة المستخدمين النهائيّين إطلاقاً**.
- المُدخَل الذي يُحلَّل هو **أصول التطبيق نفسه** (يتحكّم بها المطوّر داخل المستودع)، لا صورٌ من مستخدمٍ خارجيّ. تفعيلُ الثغرة يستلزم إدخالَ صورةٍ خبيثة إلى حزمة الأصول — أي تجاوزَ حماية المستودع أصلاً.
- محلّلا JXL/HEIF أُضيفا في `image-size` 2.x، فـ`CVE-2025-71329` **غالباً لا ينطبق** على `1.2.1` المثبَّت (يبقى ICNS وحده احتمالاً نظرياً).

### القرار وشرطُ الإغلاق
- **القبول المؤقّت + مراقبة المنبع أسبوعياً** (روتينٌ قائم منذ تنظيف #808/#810 الذي أنزل تنبيهات هذا التطبيق ٩٥ → ٢).
- **شرط الإغلاق الآليّ:** نشرُ `image-size` نسخةً `> 2.0.2` تُخرِج النطاق من الإصابة، أو ترقيةُ Metro إلى نسخةٍ تعتمد إصداراً غير مصاب ⇒ عندها `pnpm update` (أو `pnpm.overrides` بسطرٍ واحد) يحلّها، ويُحذَف هذا القسم.
- بدائلُ رُفضت: `pnpm.overrides` نحو إصدارٍ آمن (**عقيم** — كلّ `≤ 2.0.2` مصاب)، و`pnpm patch` لحدّ الحلقة يدويّاً (جهدٌ وصيانةٌ لا يبرّرهما خطرٌ ≈ صفر لتبعيّة بناءٍ على أصولٍ موثوقة).
