# الإشعارات المنبثقة والإعلانات

## ما أصبح جاهزاً

يتلقى تطبيق «مكتبة العربية» إشعارات Expo Push من حملة يديرها النظام الأساسي. يستهدف الخادم أجهزةً وافق أصحابها على الرسائل التسويقية فقط، ويعامل رسائل حالة الطلب كفئة تشغيلية مستقلة. كل حملة تمر بحالات **مسودة ← اعتماد ← جدولة ← إرسال ← اكتمال**، ويسجل النظام عدد المستلمين والمرسل والفتح والنقر.

لا يحمل نص الإشعار رقم هاتف العميل أو رصيده أو تفاصيل حساسة. كما أن الرابط المرفق لا يقبل إلا صفحة داخلية معروفة في التطبيق، مثل `/product/42` أو `/orders`.

## ما سيُنفذ عند الإصدار الرسمي

لا يلزم إجراء الآن. أثناء تجهيز النسخة الرسمية، ينشأ مشروع Expo/EAS واحد للتطبيق وتضاف قيمة `EXPO_PUBLIC_EAS_PROJECT_ID` إلى إعداد الإصدار. بعد ذلك يتم ربط Android ببيانات Firebase Cloud Messaging الخاصة بالمشروع، ويُختبر الوصول إلى جهاز فعلي. عندما يتوفر حساب Apple Developer، تضاف بيانات APNs لاختبار iPhone أيضاً.

> لا يعمل الدفع البعيد للإشعارات على Expo Go في Android الحديث. لذلك يبقى اختبار الشاشة والموافقة محلياً، بينما يختبر وصول الإشعار الفعلي من خلال بناء تطويري أو النسخة الرسمية.
