# دليل تحقيق فشل Firebase OTP على Android — 2026-08-23

## الدليل المرصود

| البند | الحالة |
|---|---|
| تطبيق Android في Firebase | موجود بالحزمة `online.alarabiya.customerstore` |
| مزود Phone Authentication | مفعّل |
| بصمة SHA-1 | مسجلة في Firebase |
| بصمة SHA-256 | مسجلة في Firebase |
| خطة Firebase | Spark |
| حد SMS الظاهر في Firebase | 10 رسائل يومياً للمشروعات الجديدة |
| سلوك الجهاز | فشل إرسال الرمز برسالة عامة؛ لم يصل رمز OTP |

## الاستنتاج الحالي

لا يوجد دليل من إعدادات Firebase على غياب التطبيق أو تعطيل المزوّد أو غياب البصمات المسجلة. تبقى الحصة/الحظر المؤقت لدى Firebase أو رمز خطأ أصلي غير معروض للمستخدم أكثر الفرضيات احتمالاً. يجب عدم إجراء محاولات SMS إضافية عشوائياً حتى يعرض التطبيق رمز خطأ مصنف وآمن أو يتم التحقق من صفحة Usage في Firebase.

## أثر الإصلاح

سيُفصل الرقم المحلي عن المفتاح `+964` في واجهة OTP، وستحافظ طبقة الخطأ على معرف مصنف غير حساس يوضح إن كان السبب حصة أو اعتماد تطبيق أو شبكة أو تحقق آلي. لا تُعرض رموز وصول أو مفاتيح أو محتوى استثناء خام للمستخدم.
