# الذاكرة التشغيلية — مكتبة العربية

**آخر تحديث:** 2026-09-25
**المنصة:** Expo SDK 54 / React Native 0.81 / Android وiOS من قاعدة كود واحدة
**معرف الحزمة:** `online.alarabiya.customerstore`

## القرارات المعتمدة

| المجال | القرار المعتمد | الحالة |
|---|---|---|
| تصميم المتجر | نمط التجارة المباشرة الفاخرة (Warm Luxury Direct Commerce) وإلغاء الكثافة والتشتت | مطبق ومفحوص بالكامل ومنشور على بيئة الإنتاج. |
| التراكب والازدحام | منع تداخل بطاقات المنتجات والحاويات في مختلف الشاشات والهواتف | مطبق ومحمي بحارس `check:responsive-layout`. |
| الكتالوج | ذاكرة قرصية لآخر استجابة صالحة وتحديث خلفي | مطبق؛ يلزم قياس جهاز فعلي مستمر. |
| البطاقات | بطاقات بيضاء عمودية، صور أغلفة كاملة، زر قلب وكمية سلة فورية | مطبق؛ تم التحقق منه بصرياً. |
| التسعير | لا يظهر الخصم أو السعر المشطوب إلا من سعر خادمي حقيقي وصالح وتطهير الخصومات الوهمية | مطبق ومغطى باختبار انحدار. |
| السلة | زر + يزيد كمية المنتج ويظهر تأكيداً وعدّاد سلة | مطبق ومغطى باختبار انحدار. |
| هاتف العراق | `+964` ثابت في اليسار الفيزيائي، والرقم المحلي LTR بأرقام لاتينية | مطبق ومختبر. |
| المفضلة | إنشاء رابط عام من عقد العميل الأصلي وترويسة الإثبات | تحقق حي سابقاً بـHTTP 200 ومفحوص. |
| SecureStore | مفاتيح صالحة ومعالجة قراءة/كتابة آمنة | مطبق ومحمي من الانهيار. |
| Firebase OTP | تطبيق Android مسجل، وتطبيق iOS مسجل مع `GoogleService-Info.plist` | مفعل في البناء الأصلي. |
| مسار الاختبار الداخلي | بناء حزمة AAB موقعة رسمياً بـ`versionCode: 21` لمسار Internal testing | تم البناء بنجاح وجاهز للطرح على Google Play. |
| CI | حراس الحوكمة والفحوصات التلقائية (TypeScript + guards + test) | 100% خضراء ومفحوصة. |

## ممنوعات تشغيلية

- لا تُعاد محاولة OTP عند الفشل من دون رمز Firebase أو لقطة الخطأ.
- لا تُدمج تغييرات خادم أو تطبيق مع فحوص فاشلة أو من دون مراجعة الاختلافات.
- لا تُعرض أسرار Firebase أو Apple أو Expo في السجل أو التوثيق.
- لا يُستخدم Expo Go لاختبار وحدات Firebase الأصلية.
