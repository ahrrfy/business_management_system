# مكتبة العربية — دليل مشروع Expo

هذا المجلد هو نقطة الدخول التشغيلية لتطبيق العملاء الأصلي «مكتبة العربية». يشرح **ما هو المشروع، أين توجد مكوناته، ما هي حالته، وكيف يُحافَظ على نظافته** من دون تخزين أسرار أو بيانات حساسة.

| الملف | الغرض |
|---|---|
| [MEMORY.md](./MEMORY.md) | ذاكرة تشغيلية محدثة: القرارات، الإصلاحات المثبتة، الحالة الحالية والعوائق. |
| [STRUCTURE.md](./STRUCTURE.md) | خريطة ملفات التطبيق ومسؤولية كل طبقة. |
| [CLEANLINESS.md](./CLEANLINESS.md) | قواعد النظافة، إدارة الأسرار، الاختبار وصيانة الاعتماديات. |
| [RELEASE.md](./RELEASE.md) | مسار APK وiOS وAAB وقائمة التحقق قبل كل إصدار. |

> لا تُخزَّن كلمات المرور أو رموز API أو مفاتيح Apple أو Firebase في هذا المجلد أو في ملفات التوثيق. تُدار القيم الحساسة عبر إعدادات المنصة أو ملفات إعداد غير مكشوفة.

## تعريف سريع

التطبيق مبني بـ **Expo SDK 54** وReact Native وExpo Router. هو تطبيق شراء عملاء مستقل عن النظام الإداري، ويستهلك واجهة المتجر العامة الآمنة في `https://alarabiya.online/api/trpc` مع حماية كتابة خاصة بالعميل الأصلي.

## أوامر التحقق الأساسية

```bash
pnpm check
pnpm test
```

اختبار اعتماد Expo الخارجي لا يعمل في الفحوص المحلية إلا إذا فُعّل صراحةً:

```bash
RUN_EAS_AUTH_TEST=1 EXPO_TOKEN=... pnpm vitest run tests/eas-token.test.ts
```

## قاعدة الإغلاق

لا يُعلن أي إصلاح متكاملاً إلا بعد تسلسل: **فحوص محلية ناجحة → بناء مستقل جديد → اختبار جهاز فعلي → توثيق النتيجة**.
